# discord-server-cloner

I run a few Discord communities and got tired of manually rebuilding servers
when migrating or setting up staging environments. This snapshots a server's
structure and recreates it elsewhere.

## install

pip install -r requirements.txt

## usage

The bot needs 'Manage Server' and 'Administrator' on both ends. Dry-run
shows what would change without touching anything.
